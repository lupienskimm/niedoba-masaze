# Masáže Niedoba

Nový web pro [masaze-niedoba.cz](https://www.masaze-niedoba.cz/) — texty a obsah z původního webu, čtyři přepínatelné vizuální styly.

## Styly (přepínač dole)

1. **Kombi** — pravidla z designové knihovny + brand zelená Niedoba  
2. **Saltwater** — silně inspirováno [saltwatermassage.com](https://saltwatermassage.com/)  
3. **Medwest** — silně inspirováno [medwest.plus](https://medwest.plus/)  
4. **McGarr** — silně inspirováno [massagemcgarr.com](https://massagemcgarr.com/)

## Spuštění

```bash
npm install
npm run dev
```

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4 + vlastní theme tokeny (`data-theme`)
